## 项目简介

本项目为 2026 年山东大学暑期社会实践「芯溯红迹」团队的核心产出，包含两个子项目：

| 子项目 | 形态 | 定位 |
| --- | --- | --- |
| **hongmai-quancheng** | 响应式静态网站（单文件） | 成果展示平台：文物档案、口述史、时间轴、3D 数字孪生 |
| **hongmai-miniprogram** | 微信原生小程序 | 互动传播载体：文物图鉴、知识闯关、留言板、伪 3D 展品 |

设计语言统一：**庄重 + 现代**，主色调为中国红（`#B91C1C`）配米白（`#F5EFE0`）与暗灰，全端响应式适配。

## 一、红脉泉城网站（hongmai-quancheng）

### 简介

面向 PC / 移动端的单页响应式展示网站，将团队走访 5 处纪念地、整理 12 份文物档案、采集 8 段口述史的实践成果可视化呈现。

### 核心板块

- **主视觉区**：项目主题与数据概览（5 处纪念地 / 12 份档案 / 8 段口述史 / 200+ 人次覆盖）
- **实践成果概览**：走访、建档、口述三大成果摘要
- **革命文物档案**：6 件重点文物，含编号、年代、历史脉络、思想价值与保护传承
- **红色时间轴**：4 个关键历史节点（含 1947.02 莱芜战役等，史实已校正）
- **3D 数字孪生**：基于 GLB 模型的交互式坦克展示（Web 端）
- **精神图谱 / 研学路线 / 宣讲纪实 / 留言墙**：精神提炼与传播成果

### 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- [model-viewer](https://modelviewer.dev/) + GLB 3D 模型（[AI 文生 3D 教学示意](hongmai-quancheng/assets/models/)）
- 图片与模型以 base64 内嵌，**单文件即可分发、双击即可打开**

### 本地运行

```bash
# 直接双击打开，或用任意静态服务器：
cd hongmai-quancheng
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

> ⚠️ 注意：`index.html` 约 52MB（资源内嵌），GitHub 单文件 100MB 限制内可正常托管；若加载较慢，可后续改为外链资源。

## 二、红脉泉城小程序（hongmai-miniprogram）

### 简介

微信原生小程序，将网站成果浓缩为 5 个 tab 页 + 2 个分包页的轻量互动体验，总计约 2.1MB，全资源本地化，加载流畅。

### 功能一览

| 页面 | 功能 |
| --- | --- |
| **首页** | 主视觉、数据指标、板块导览、红色时间轴、研学路线 |
| **文物图鉴** | 14 件文物卡片 + 分类筛选 → 分包详情页（大图 / 历史脉络 / 思想价值 / 保护传承） |
| **知识闯关** | 20 题济南·山东革命史题库随机抽 10 题，即时解析、称号评级、Canvas 成绩卡保存相册 |
| **关于我们** | 团队 9 人 + 指导老师、口述史、精神图谱、实践留言墙 |
| **留言板** | 云开发读写 + 点赞（本地持久化）+ 内容校验 + **本地降级兜底** |
| **伪 3D 坦克**（分包） | GLB → 24 帧环绕序列图，手指拖动旋转（纯前端实现，无需 web-view） |

### 技术栈

- 微信小程序原生框架（WXML / WXSS / JS）
- 分包机制：主包约 467KB，分包 A（文物详情）698KB，分包 B（3D 坦克）877KB，远低于 2MB/包、20MB/总限制
- 微信云开发（仅留言板使用，未开通时自动降级为本地演示模式）
- Python + Pillow / NumPy 构建脚本：图片压缩、图标生成、GLB 帧渲染（`tools/`）

### 快速开始

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择 `hongmai-miniprogram` 目录
3. 填入小程序 AppID（当前配置 `wx7a8649a8938a9ec1`，可用游客模式预览）
4. 点击「编译」即可在模拟器运行

### 留言板云开发（可选）

留言板默认运行在**本地降级模式**（展示内置留言 + 本地提交演示）。如需真正的多人实时留言：

1. 微信开发者工具 → 顶部「云开发」→ 开通云环境
2. 在云开发控制台新建数据库集合 `messages`
3. 将 `utils/config.js` 中的 `cloudEnv` 改为你的云环境 ID
4. 重新编译，留言即写入云端、全网可见

> 安全提示：请勿在代码或提交记录中泄露小程序 `AppSecret` 等敏感凭据；云环境 ID 不属于敏感信息。
